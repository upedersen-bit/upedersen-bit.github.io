# Two Names, Two Countries

The life of Niels Christian Olesen Damborg (1821–1899), from Himmerland, Denmark, to Washington County, Nebraska.
A family history compiled by Leo Pedersen and Ulrik Damborg.

Read it at https://upedersen-bit.github.io/

This repository holds the published website. The text is maintained in the biography document and the site is rebuilt from it.
